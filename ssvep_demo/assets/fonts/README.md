# Bundled CJK font

`NotoSansSC-Regular.otf` is the static Simplified Chinese subset OTF from the
official [notofonts/noto-cjk](https://github.com/notofonts/noto-cjk) repository:

`Sans/SubsetOTF/SC/NotoSansSC-Regular.otf` at commit
`f8d157532fbfaeda587e826d4cd5b21a49186f7c`.

Its internal family name is `Noto Sans SC`. The SHA-256 is
`faa6c9df652116dde789d351359f3d7e5d2285a2b2a1f04a2d7244df706d5ea9`.
